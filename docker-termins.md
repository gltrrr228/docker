# Ключевые понятия Docker'а

| Понятие | Описание | Аналогия | 
| --- | --- | --- | 
| Образ (image) | Неизменяемый шаблон: файловая система + команда запуска | Установочный файл |
| Контейнер | Запущенный экземпляр образа | Запущенная программа (приложение) |
| Реестр (registry) | Хранилище образов (например Docker Hub) | Магазин приложений |
| Dockerfile | Файл с описанием сборки образа | Руководство по установке |
